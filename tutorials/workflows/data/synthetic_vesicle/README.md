# Synthetic vesicle dataset

This directory is the target location for the shared, fully synthetic data
used by the task-oriented workflow tutorials.

The field is generated by
`../../_data_generation/generate_synthetic_vesicle_q.py`; no experimental
dataset is copied or redistributed.  The construction contains a rough 3-D
Q field, a vesicle-like interface with imperfect inner tangential anchoring,
different interior/exterior textures, two long spanning disclinations, one
shorter chord, and one closed defect loop.

The generator writes:

- `Q.npy`: noisy five-component Q tensor used as the workflow input;
- `Q_clean_ground_truth.npy`: the same analytic field before Q-space noise;
- `director_ground_truth.npy`: director used to construct the clean field;
- `S_ground_truth.npy`: scalar-order ground truth;
- `mask_vesicle.npy`: binary vesicle-interior mask;
- `defect_lines_ground_truth.npz`: named centreline coordinates;
- `metadata.json`: provenance and generation parameters.

Regenerate the files with

```bash
python tutorials/workflows/_data_generation/generate_synthetic_vesicle_q.py
```

The default random seed is fixed, so the standard dataset is reproducible.

This directory is the output location for the shared synthetic Q-field used by
the task-oriented workflow tutorials.

The dataset is intentionally **fully synthetic**.  It is not derived from,
fitted to, or copied from the experimental vesicle data that motivated the
workflow examples.

Generate the arrays with:

```bash
python tutorials/workflows/_data_generation/generate_synthetic_vesicle_q.py
```

Generated files:

- `Q.npy` — rough five-component Q field used as the tutorial input;
- `Q_clean_ground_truth.npy` — the same analytic field before added Q noise;
- `director_ground_truth.npy` — pre-noise director field;
- `S_ground_truth.npy` — pre-noise scalar-order field;
- `mask_vesicle.npy` — binary vesicle-interior mask;
- `defect_lines_ground_truth.npz` — sampled centreline points for the four
  imposed disclinations;
- `metadata.json` — geometry, defect charges, noise amplitudes, and provenance.

The generator uses a fixed seed by default, so regenerated tutorial data are
deterministic.
