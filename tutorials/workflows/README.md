# Nematics3D workflows

This directory contains complete, task-oriented examples built from multiple
Nematics3D components.

Unlike `tutorials/guided`, which teaches the library progressively, and
`tutorials/reference`, which documents individual APIs, these notebooks start
from a scientific or data-analysis task and carry it through to a usable
result.

Initial workflow topics are expected to include:

- smoothing noisy nematic fields;
- estimating relaxation or correlation lengths;
- detecting and reconstructing disclination lines;
- studying the geometry and topology of disclination lines;
- visualizing director fields around interfaces and defects.

Several workflows may intentionally share the same synthetic example dataset
so that users can see how one dataset is reused across different analyses.

## Shared synthetic vesicle dataset

The first shared dataset is generated by
`_data_generation/generate_synthetic_vesicle_q.py`.  It is deliberately
synthetic rather than copied from experimental data, but it is designed to
retain several features that make experimental nematic data interesting to
analyse:

- a visibly rough, imperfect 3-D Q field;
- a vesicle-like interior with a distinct exterior texture;
- approximately tangential director anchoring near the inner vesicle surface;
- four disclination lines inside the vesicle, including two long lines that
  cross almost the full vesicle diameter, one shorter peripheral chord, and
  one closed disclination loop;
- saved ground truth for the vesicle mask, scalar order, director field, and
  defect-line centrelines.

The same dataset is intended to support workflows on smoothing, interface
alignment, correlation/relaxation lengths, defect detection, line
reconstruction, and defect topology.

Regenerate it with a fixed random seed by running:

```bash
python tutorials/workflows/_data_generation/generate_synthetic_vesicle_q.py
```

The generated files are written to `tutorials/workflows/data/synthetic_vesicle/`.
